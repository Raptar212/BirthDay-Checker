# BirthDay Checker

Напоминалка о днях рождения, именинах, годовщинах и праздниках для Windows и Android. На ПК живёт
в трее и заранее напоминает о ближайших событиях.

> **Версия 2.5.2** (ПК) — [Releases](https://github.com/Raptar212/BirthDay-Checker/releases/latest) ·
> **0.67.0** (телефон, Android) — [mobile-v0.67.0](https://github.com/Raptar212/BirthDay-Checker/releases/tag/mobile-v0.67.0)

## Установка

Windows 10 или 11, 64-бит: запустите `BirthdayChecker-Setup-<версия>.exe` из
[Releases](https://github.com/Raptar212/BirthDay-Checker/releases). Права администратора не нужны,
программа ставится в `%LOCALAPPDATA%\Programs\BirthDay Checker` и дальше обновляется сама.

### Первый запуск

Иконка появится в трее (может быть спрятана под стрелкой `^`). Двойной клик — список записей,
правый клик — меню. При первой установке в списке уже есть праздники: Новый год, Рождество,
Пасха, День отца и День матери; обновление установщиком список не трогает.

## Телефон (Android)

Приложение для Android в разработке: список, календарь, редактор записей, ежедневное уведомление
и виджет «Проверить»; новую версию находит само (при открытии раз в день или ⋮ → «Проверить
обновления»), сверяет SHA-256 и ставит сама: на Android 12+ по Wi-Fi без вопросов, когда вы
выходите из приложения, на Android 8–11 — через системное окно «Установить». Нужно один раз разрешить
приложению «Установку неизвестных приложений». APK — в [Releases](https://github.com/Raptar212/BirthDay-Checker/releases)
(теги `mobile-v*`). Обмен записями с ПК: на телефоне ⋮ → «Поделиться» отправляет `entries.json`,
на ПК его принимает «Ещё ▾» → «Импорт»; в обратную сторону — ⋮ → «Добавить из файла».

## Файлы программы

| Файл | Что в нём |
|---|---|
| `entries.json` | Ваши записи (UTF-8, можно править вручную) |
| `settings.json` | Настройки, колонки, теги и события |
| `data\entries.json.bak` | Предыдущая версия списка |
| `data\state.json`, `data\errors.log` | Служебное: дата последней проверки; журнал ошибок |
| `Backup\backup-BDC-<дата>.json` | Автокопия списка (период — в настройках) |
