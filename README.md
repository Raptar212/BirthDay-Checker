# BirthDay Checker

Напоминалка о днях рождения, именинах, годовщинах и праздниках для Windows. Живёт в трее,
проверяет список по таймеру и показывает ближайшие события. Замена старой программы Birthday
v1.2.2.8 (2012): записи из неё переносятся одной командой.

> **Версия 2.2.0.** Установщик — в [Releases](https://github.com/Raptar212/BirthDay-Checker/releases/latest).

## Возможности

- Даты трёх видов: фиксированная (год можно не указывать), плавающая («2-е воскресенье мая») и
  от православной Пасхи (Радоница, Троица…).
- Напоминание заранее — за 1–5 дней, 1–5 недель, 1–3 месяца, можно несколько; в сам день — всегда.
  Дни, пропущенные при выключенном компьютере, догоняются при следующем запуске.
- Окно напоминания со всеми событиями сразу, «Напомнить позже» и «Больше не напоминать сегодня»;
  позиция, автозакрытие, звук, цвета, фон. Либо простое уведомление Windows.
- Список с сортировкой, фильтрами, поиском (`Ctrl+F`), тегами и цветом строк, групповой правкой
  и своими столбцами. Справа — календарь на год со значками событий.
- Отчёт о грядущих событиях; экспорт и импорт CSV, TXT, MD, JSON; автоматическая резервная копия.
- Светлая и тёмная тема. Почти не нагружает систему: ~15 МБ памяти, процессор в простое не занят.

## Установка

Windows 10 или 11, 64-бит; .NET ставить не нужно. Запустите `BirthdayChecker-Setup-<версия>.exe`
из [Releases](https://github.com/Raptar212/BirthDay-Checker/releases). Права администратора не
нужны: программа ставится в `%LOCALAPPDATA%\Programs\BirthDay Checker` и хранит данные там же,
поэтому не ставьте её в `Program Files`.

- **Обновление** — установщик новой версии: заменит программу, ваши записи и настройки не тронет.
- **Удаление** — «Параметры → Приложения → BirthDay Checker». Файлы с записями остаются в папке
  программы.
- **Автозапуск** — «Настройки» → «Запускать вместе с Windows».

## Первый запуск

1. Иконка появится в трее (может быть спрятана под стрелкой `^`). Двойной клик — список записей,
   правый клик — меню.
2. Перенос из старой программы: меню трея → **«Импорт из старой программы…»** → txt-экспорт
   старой Birthday. Программа покажет, что стоит проверить вручную (дубли, год 2022 вместо года
   рождения и т. п.).

## Телефон (Android)

Приложение для Android в разработке: список, календарь, редактор записей, ежедневное уведомление
и виджет «Проверить». APK — в [Releases](https://github.com/Raptar212/BirthDay-Checker/releases)
(теги `mobile-v*`). Обмен записями с ПК: на телефоне ⋮ → «Поделиться» отправляет `entries.json`,
на ПК его принимает «Ещё ▾» → «Импорт»; в обратную сторону — ⋮ → «Добавить из файла».

## Файлы программы

| Файл | Что в нём |
|---|---|
| `entries.json` | Ваши записи (UTF-8, можно править вручную) |
| `settings.json` | Настройки, колонки, теги и события |
| `data\entries.json.bak` | Предыдущая версия списка |
| `data\state.json`, `data\errors.log` | Служебное: дата последней проверки; журнал ошибок |
| `Backup\backup-BDC-<дата>.json` | Автокопия списка (период — в настройках) |

Если программа пишет, что файл записей не прочитан, — она его не меняет. Исправьте ошибку из
сообщения или верните `data\entries.json.bak` на место `entries.json`. Файл читается строго:
опечатка в имени поля — ошибка с указанием места.

## Разработка

Нужен .NET 10 SDK, для установщика — Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

```powershell
dotnet test                                  # тесты
dotnet run --project src\BirthdayChecker.App # запуск
.\installer\build.ps1                        # → artifacts\BirthdayChecker-Setup-<версия>.exe
```

`src/BirthdayChecker.Core` — логика без UI, `src/BirthdayChecker.App` — WPF-приложение,
`tests/BirthdayChecker.Tests` — xUnit, `mobile/` — Android (.NET MAUI, то же ядро):

```powershell
dotnet workload install maui-android     # один раз, от администратора
dotnet build -t:InstallAndroidDependencies -f net10.0-android mobile\BirthdayChecker.Mobile `
  -p:AcceptAndroidSDKLicenses=true       # один раз: Android SDK и JDK в %LocalAppData%\Android
mobile\build.ps1                         # подписанный artifacts\BirthdayChecker-Mobile-<версия>.apk
```

Задачи — ветки `BDC-N`, в `main` только через PR.
